# Closed-Book Recall Diagnostic

Run this diagnostic in the SAME chat that completed Cohort-1 priming.

The chat must remain in CLOSED-BOOK MODE.

The attached diagnostic exam itself is the only new input allowed.

Do not use:

- tools
- server
- repository
- Project Brain
- Source Snapshot
- GitHub
- web
- search
- connectors
- previous chats
- any other file
- any lookup

This diagnostic is intentionally different from free recall.

It measures two additional properties:

1. Recognition
2. Cued recall

For recognition questions:

- always choose the best option
- do not return null merely because confidence is low

For cued-recall questions:

- answer from retained Priming context
- do not perform external verification

The diagnostic score must never replace the free-recall score.

Its purpose is to determine whether Priming information is still
accessible when a cue or candidate answer is provided.
