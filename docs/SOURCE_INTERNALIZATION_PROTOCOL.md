# Source Internalization Protocol

This layer is deliberately separate from retrieval mastery.

Three metrics must never be conflated:
1. **Conceptual source recall** — explain implementation/relationships without lookup.
2. **Topology/name recall** — file/function/route names and placement without lookup.
3. **Verbatim source recall** — reproduce exact source lines/blocks without lookup.

`SOURCE_INTERNALIZATION_BRAIN.json` provides a compressed symbol-centric representation plus exact 8-line source blocks. `SYMBOL_TOPOLOGY_MEMORY_PACK.json` provides the compact file→ordered-symbol and route→handler topology for repeated ingestion.

Any score labeled *unaided* must be produced by a fresh/blind answer phase before lookup/grading. Retrieval success must not be counted as memory success.
