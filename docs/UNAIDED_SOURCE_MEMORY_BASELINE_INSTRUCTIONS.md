# Unaided Source Memory Baseline — Fresh Chat

This test is intentionally different from the project's retrieval exams.

- Do **not** connect to the server.
- Do **not** open repository files, Project Brain, Knowledge files, GitHub, prior chats, search, tools, or any source snapshot.
- Read only the public questions in `UNAIDED_SOURCE_MEMORY_BASELINE_EXAM.json` if they are supplied to you as the test prompt/file. Answer only from what is already present in your active model/chat recall.
- If you do not remember an answer, use `null`; do not guess via lookup.
- Freeze the answers before grading.

The result measures unaided recall. It must never be replaced by a retrieval score.
