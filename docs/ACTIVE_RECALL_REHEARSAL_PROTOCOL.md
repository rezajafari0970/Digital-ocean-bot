# Active Recall / Associative Rehearsal Protocol

Cohort-1 diagnostic showed high recognition but weak generative access. Training therefore changes from passive ingestion to **read → close → generate → correct → regenerate**.

For each priming pack, in manifest order:
1. Read the original pack once.
2. Stop looking at it.
3. Read its matching `*-recall.json` and answer from memory without reopening the pack/correction.
4. Only after answers are committed, read `*-correction.json` and compare.
5. Close correction material and immediately regenerate only the missed answers once more.
6. Move to the next pack.

Topology rehearsal is bidirectional (symbol→file and neighbor→next) plus route→handler. Conceptual rehearsal requires generative core facts. Verbatim rehearsal uses both whole-block reproduction and first-line continuation.

After all Cohort-1 units, enter CLOSED-BOOK MODE and run a **new holdout**, never the rehearsal questions. Recognition scores are diagnostic only; success target is improved cued/free recall.
